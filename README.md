## Structure

```
portfolio-pro/
├── index.html    → structure de la page
├── style.css     → mise en forme et animations
├── script.js     → apparition au scroll, compteurs KPI animés
└── README.md     → ce fichier
```

## Voir le site en local

```bash
python3 -m http.server 8000
```
Puis ouvrez http://localhost:8000

## Publier en ligne avec GitHub Pages

1. Dans les paramètres du dépôt GitHub → **Settings → Pages**
2. Source : branche `main`, dossier `/ (root)`
3. Le site sera accessible à une adresse du type
   `https://mor270.github.io/portfolio-pro/`
